# 2026-09-14

## 桌面端可运行构建（Electron desktop）

目标：把 `packages/desktop` 构建成可运行版本（`electron .` / `pnpm electron` 能真正拉起窗口）。

- **补全缺失的自启动引导**：新增 `packages/desktop/src/main/bootstrap.ts`——静态 `import { app, BrowserWindow, ipcMain, safeStorage } from 'electron'`，适配为 `ElectronModule` 后调用 `boot()`。
  - 原 `electron-main.ts` 只导出 `boot()`、无自启动，且 package.json 的 `main`/`electron` 脚本指向它 → 运行即退出。
  - 已把 `main` 与 `scripts.electron` 改指向 `dist/main/bootstrap.js`。
- **产物路径坑**：desktop 的 `rootDir: "src"`，故 `src/preload.ts` → **`dist/preload.js`（扁平）**，不是 `dist/preload/preload.js`；bootstrap 的 `preloadPath` 必须按扁平路径解析。
- **构建命令**（bash coreutils 不可靠，用 PowerShell + 绝对路径）：
  - `node .../typescript/bin/tsc -p packages/desktop/tsconfig.json`（注意 bin 是 `tsc` 无扩展名）
  - `node .../vite/bin/vite.js build --config .../packages/desktop/vite.config.ts`（**不能加 `--root`**，config 里已设 root）
- **验证渲染进程（关键手法）**：真实 `dist/renderer` 必须经**本地 http 静态服务**渲染——`file://` 下 ES module `<script>` 会被 Chrome 以 CORS（origin `null`）拦死，UI 完全不挂载。脚本 `.shot/shot-real.cjs`：node http 服务 + puppeteer-core（在 `.shot/node_modules`）+ 本地 Chrome，`evaluateOnNewDocument` 注入 `window.mozi` mock（**必须传函数，不能传字符串**）。
  - 侧栏导航项是 `<div class="nav-item">`（非 button）；会话项是 `.session-item`，显示名 = `model ?? id.slice(0,12)`。
  - 侧栏 nav 仅含 chat/pulls/schedule/plugins/security；仪表盘/设置/子智能体是**顶栏 tab**（仅 nav∈chat/subagents/dashboard/settings 时可见）→ 截图顺序要先顶栏后侧栏。`skills` 视图当前无入口。
- **验证主进程装配**：mock electron 跑真实 `dist/main/electron-main.js` 的 `boot()` → whenReady / loadFile(renderer) / **21 个 IPC handler** / shutdown 全通过（`.build/msmoke.mjs` → `.build/msmoke.log`）。
- **环境限制**：本沙箱**无法启动 electron.exe**（GUI 子系统进程连最小 `emin.cjs` 都不执行，sandbox 关掉也一样；node.exe 正常）。故 GUI 实机启动无法在此验证，只能靠上述 mock-boot + Chrome 渲染佐证。
- **发现（未改）**：`packages/desktop/index.html` 的 CSP（`style-src 'self' 'unsafe-inline'`）会拦截 `styles.css` 顶部的 Google Fonts `@import`，设计字体回退到系统字体（Segoe UI / PingFang SC / 雅黑）。与仓库「零外部依赖 + 进程安全」意图一致，保持不动。
- **清理**：删除 `_r.txt`/`_s.txt`、`packages/desktop/_probe.mjs`、`packages/desktop/run-shot.cjs`；`.build/` 与 `.shot/` 已加入 `.gitignore`（临时构建/验证目录，不入库）。
