## 五、关键决策记录（M1 轮）

- **零重依赖策略**：OpenAI 兼容 Provider 用 Node 内置 `fetch` + 手写 SSE 解析，不引 `openai` SDK；glob 自实现；工具参数校验用轻量手写校验而非 ajv。契合 ADR-008。
- **ScriptedProvider 优先**：测试基建先行，所有 loop 行为用确定性回放，零 API 成本。
- **M1 不含**：PatchEngine（M2）、沙箱 L2/L3（M3）、MCP（M3.5）、压缩（M2）、子智能体（M2）。引擎 API 预留扩展点。

### M2 轮补充决策

- **子智能体 = 同实例 `engine.run()` 另一次调用**（Supervisor 模式），不引入第二套引擎；父子 session 锁按 sessionId 独立，天然支持嵌套。
- **桥接事件走宿主实时通道**：父 `run()` 生成器在 `await` 工具执行期间无法 yield，故 `subagent.*` 事件经 `onEvent`/`emitLive` 即时送达；`task` 调用并入「读并行组」（meta 级），受 Supervisor 并发槽控流。
- **审批冒泡消竞态**：冒泡事件同步送达后 UI 可能立即 `resolve`，早于子会话 `approval.request` 注册；`InteractiveApprovalGateway` 增加早期裁决缓存。
- **每轮派发计数同步预留**：并行 `task` 调用下 `subSpawnCount` 读取存在竞态，改为 Supervisor 内同步占位的 `turnSlots`，turn 边界重置。
- **子会话事件单一事实源**：引擎按 `session.id` 落盘 `subs/<id>/events.jsonl`，Supervisor 不再重复 append（否则事件翻倍）。
- **首次压缩不受 minInterval 约束**：`turnsSinceLastCompact = -1` 哨兵表示「从未压缩」。
